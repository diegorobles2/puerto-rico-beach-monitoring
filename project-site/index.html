Project overview

Planning a beach visit means checking advisories and forecasts published by different agencies. This capstone brings them together by beach so visitors can see what each source reported and when.

Find a beach
Browse the interactive map, search by name, filter by municipality, or use your location to sort beaches by distance.
Compare conditions
View water-quality measurements and advisories from Puerto Rico’s Department of Natural and Environmental Resources (DRNA) alongside National Weather Service (NWS) rip-current risk and active alerts.
Check the source
See source links and timestamps for each condition. The app flags stale and unavailable data and labels historical readings where available.

System architecture

The backend imports agency data into PostgreSQL. The React app reads the stored conditions through the NestJS REST API.
